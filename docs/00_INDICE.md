## Criterios para crear la documentación

1. Mantener un Markdown por unidad y este índice general.
2. Integrar la información por tema, evitando repeticiones.
3. Conservar conceptos, procedimientos y ejemplos de código relevantes.
4. Identificar las fuentes: archivo y página; video y marca de tiempo,
   cuando estén disponibles.
5. Diferenciar el contenido de la cátedra de las aclaraciones añadidas.
6. Señalar contradicciones o información incompleta.
7. No inventar contenido de materiales todavía no incorporados.
8. Actualizar este índice al incorporar cada fuente.
9. Marcar como parcial cuando haya fuentes o contenidos concretos pendientes,
   identificándolos. No suponer que faltan audiovisuales: su existencia y aporte
   se evaluarán después en cada unidad.
